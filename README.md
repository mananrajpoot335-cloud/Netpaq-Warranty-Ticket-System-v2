# Netpaq Warranty Ticket System v2.0

### Advanced Warranty Management with LAN Synchronization & Activity Logs

Netpaq Warranty Ticket System is a web-based warranty management solution designed to simplify warranty tracking, ticket handling, and multi-PC collaboration.

Version 2.0 introduces an improved Master/Client architecture with two-way LAN synchronization and integrated activity logging.

## Key Features

- Two-Way LAN Data Synchronization
- Master PC & Client PC Architecture
- Shared Warranty Records
- Activity Logs & Login Tracking
- Warranty Registration & Management
- Ticket Management
- Dashboard & Analytics
- Payment & Resolution Tracking
- RMA & Device Replacement
- Advanced Search
- PDF Reports
- Backup & Restore

## Project Files

| File | Description |
|---|---|
| Warranty HTML File | Main application |
| Windows Batch File (.bat) | Starts the local synchronization server |

## Installation & Usage

1. Download the project files from this repository.
2. Extract the files if downloaded as a ZIP.
3. Keep the application HTML and server batch file in their required folder structure.
4. Start the server using the provided Windows Batch File.
5. Open the Warranty System HTML application.
6. Configure the Master PC and Client PC according to the network setup.

**Important:** Both PCs must have the required LAN connectivity and server configuration for synchronization.

## System Architecture

**Master PC:** Central synchronization server.

**Client PC:** Connects to the Master PC to access and synchronize shared warranty data.
